# PRODUCT_VISION.md — حجوزاتي (Hajozati)

## 1. رؤية المنتج
"حجوزاتي" هو تطبيق حجز فنادق عصري، مخصص في مرحلته الأولى للسوق العراقي، يقدّم تجربة حجز بسيطة وسريعة وشفافة، مستوحاة من بساطة تجربة Flamingo: بحث سريع → نتائج واضحة → حجز مؤكد خلال دقائق، بدون تعقيد أو خطوات زائدة.

## 2. هدف المنتج
- تسهيل حجز الفنادق داخل العراق للمسافرين المحليين والزوار.
- توحيد تجربة البحث والحجز في تطبيق واحد بدلًا من الاتصال المباشر بالفنادق أو استخدام منصات غير محلية غير ملائمة للسوق العراقي.
- بناء منصّة قابلة للتوسع مستقبلًا لتشمل شركاء فنادق (Hotel Manager) ولوحة إدارة مركزية (Admin).

## 3. المشكلة التي يحلها
- غياب منصة حجز فنادق محلية بسيطة وموثوقة مخصصة للعراق.
- صعوبة معرفة توفر الغرف والأسعار الحقيقية بدون اتصال مباشر بالفندق.
- تجربة حجز مجزأة (اتصال هاتفي، واتساب، مواقع غير موحّدة) بدون سجل حجوزات مركزي للمستخدم.

## 4. الفئة المستهدفة
- **المسافر المحلي**: يبحث عن فندق ضمن محافظة عراقية معينة لأسباب عمل أو سياحة أو زيارة عائلية.
- **الزائر / السائح**: يستكشف الوجهات السياحية في العراق ويحتاج فنادق قريبة منها.
- (مستقبلًا) **مدير الفندق**: يدير غرف وأسعار وحجوزات فندقه.
- (مستقبلًا) **مسؤول المنصة (Admin)**: يدير الفنادق والمستخدمين والمحتوى.

## 5. رحلة المستخدم (User Journey) المختصرة
فتح التطبيق → اختيار اللغة/الدخول → الرئيسية → اختيار المحافظة وتواريخ الوصول/المغادرة وعدد الضيوف → بحث → نتائج → تفاصيل الفندق → اختيار الغرفة → بيانات الحجز → مراجعة → تأكيد → رقم حجز + QR → إضافة إلى "حجوزاتي".

## 6. القيمة التي يقدمها التطبيق
- سرعة: بحث وحجز في أقل عدد ممكن من الخطوات.
- وضوح: أسعار وتوفر حقيقي بدون مفاجآت.
- محلية: مبني حول محافظات العراق والوجهات السياحية العراقية.
- ثقة: رقم حجز + QR Code كإثبات رسمي للحجز.
- ثنائية اللغة: عربي (RTL) وإنجليزي (LTR)، مع تجهيز معماري للفارسية مستقبلًا.

## 7. نطاق الإصدار الأول (MVP)
- تسجيل/دخول أساسي.
- الصفحة الرئيسية مع بطاقة بحث (محافظة، تواريخ، بالغين، أطفال).
- نتائج البحث + تفاصيل الفندق + اختيار الغرفة.
- تدفق حجز كامل (Booking Draft → مراجعة → تأكيد → QR).
- صفحة "حجوزاتي" (Upcoming / Completed / Cancelled).
- المفضلة.
- الملف الشخصي الأساسي.
- دعم عربي/إنجليزي كامل (RTL/LTR).

## 8. الرؤية المستقبلية (Future Vision)
- ميزة الفنادق القريبة (Nearby Hotels) باستخدام الموقع الجغرافي.
- قسم "اكتشف العراق" للوجهات السياحية.
- لوحة إدارة الفندق (Hotel Manager Dashboard).
- لوحة إدارة عامة (Admin Dashboard).
- ربط Backend حقيقي وقاعدة بيانات.
- إشعارات، عروض، وبرنامج ولاء محتمل.
- توسع جغرافي خارج العراق ودعم لغة فارسية كاملة.
